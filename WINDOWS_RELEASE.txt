元件库桥 PartsBridge AD 0.3.8（Windows x64）
=============================================

维护与发布：foke

使用方法
--------
1. 完整解压 ZIP，保留 PartsBridge-AD.exe 与 _internal 文件夹的相对位置。
2. 双击 PartsBridge-AD.exe。
3. 搜索并核对元件；只把已经确认的 C 编号加入生成队列。
4. 选择自己电脑上存在且可写的长期总库目录，点击“追加到总库”。
5. 首次使用在 Altium Designer 的 Components 面板安装两份文件库；以后追加默认请求刷新。
6. 对照数据手册核对 Pin 1、引脚和焊盘。

追加语义
--------
- 总库目录只保留 LCSC.SchLib 和 LCSC.PcbLib，不写原理图。
- 历史元件保留；已有 C 编号跳过，不下载、不自动更新模型。
- 追加前请在 Altium 中保存并关闭这两份库；应用自身锁不能阻止 Altium 对已打开文件的写入。
- manifest.json、last-run.json、锁和每次发布前备份位于
  %LOCALAPPDATA%\PartsBridge-AD 下的每库 state_directory，运行结果会显示实际维护目录。
- 上次明确选择的总库目录偏好保存在 %LOCALAPPDATA%\PartsBridge-AD。
- 无目录偏好时默认 G:\dontdel\AD\_Lib；首次使用请主动选目录，没有 G 盘时必须改选。
- manifest 是库外索引；完整旧库即使没有旧 manifest，也可从原生库重建索引后直接接入，不要求重新下载。
- 默认请求嵌入 3D；无 3D 资源会记录警告，工程使用前仍须人工复核。
- 缺少或损坏库文件、冲突或并发修改时安全中止，不覆盖旧库。
- 中断恢复仅在文件仍匹配事务记录的已知 before/after SHA-256 时自动处理；未知外部修改会停止恢复。

重要边界
--------
- 当前免登录模式使用公开数据，不读取商城 Cookie 或账号。
- 正式开放平台适配层只有签名与配置检查，尚未实现获批业务查询；公开数据模式不需要账号密钥。
- 库文件通过结构和回读校验不等于工程签核；投板前仍须核对数据手册和封装。
- 当前个人构建未使用商业代码签名证书。请先核对随包 SHA256SUMS.txt。
